Operation Stress Test

  1. Every method we have is written once. From that one source the page builds three versions: float64 (timed), float32 (every + − × ÷, √, ∛, cos, acos rounded to float32; a × b ± c rounded once), and counted (every operation tallied, for the Skylake model).
  2. The inputs are real: the step 10 pieces of the chosen mesh, seen by a real camera at 200².
  3. Answer key: each piece's surface sampled densely (several samples per pixel), independent of every method below. A pixel counts as decided for a piece when the piece covers, or misses, its whole 3 × 3 block; detection errors are counted only there. Exact u, v and depth come from the winning piece's quadric along the pixel's ray, at the root that matches the sampled depth.
  4. Slide = where a method's (u, v) puts you on the surface, P(u, v), against where the pixel really looks, in % of the average edge length.

Who wins a pixel

MethodTimeMemoryEntries

Same entries for all (spans + sign rule): piece, u, v, depth. Memory counts what is kept per pixel (lists: the entries and their links).

Backup, not implemented: if a pixel ever needs several entries (layers), the lists can be packed too: pass 1 first counts the entries per pixel, a running sum gives each pixel one block of its own, then pass 1 writes the entries straight into those blocks; pass 2 reads each block in order, with no links to follow.

Packed: cache layout

PipelineMeasured ns per pixel walked: objects → packedOperations per pixel walked (counted, packed)Model cycles per pixel walkedSame result as unpacked?

Packed = all pieces' numbers in one flat array, each piece's block ordered by how often a number is used (per pixel → per span → per row → per frame → P(u, v)). At a span's first pixel the values that change along the row (ray direction, a and b of the quadratic, the 4 planes' n·d, the edge K values) are set up once; every further pixel only adds fixed steps, so nothing is read from the array inside a span. Output: separate arrays (depth float32, piece 16-bit, u and v 16-bit fixed point = 10 bytes per pixel). “Unpacked” = the per-piece objects, every pixel computed from scratch.
