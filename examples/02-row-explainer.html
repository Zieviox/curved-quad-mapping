Rows and Pixels

  1. Top view is the screen: a 14 × 14 grid of big pixels with one curved patch on it.
  2. Bottom view is the same patch unrolled to its flat (u, v) square. Each point is painted with the checker color of the pixel it lands in, so you see the pixel cells as the patch sees them.
  3. Switch Flat and Curved. Flat: the cells are a straight grid. Curved: the cells bend and tilt.
  4. The blue line is one row: one value of v. The dots are where it crosses a pixel edge, solved exactly. It only touches the pixels it passes through.
  5. Press Add row at different v values until no red pixel is left. Choosing those v values exactly is the open problem.
